# MorriganShell

**A minimal, dark and personalized desktop shell for Linux.**

My personal desktop shell project, built around Quickshell, QML and Go, with a focus on visual consistency, modularity and a refined desktop experience.

## Overview

MorriganShell is a personal desktop shell project focused on building a consistent, minimal and customizable Linux desktop environment.

The project focuses on:

- **Minimalism** — a clean interface with a restrained dark color palette.
- **Visual consistency** — cohesive components, typography, spacing and interaction patterns.
- **Customization** — a desktop environment tailored to my preferences.
- **Modularity** — independent components organized into a structured architecture.
- **Maintainability** — reusable components and organized code that can evolve over time.
